# SanadApp

Module d'authentification moderne pour la plateforme sociale Sanad.

## Frontend

- Routes : /auth/login, /auth/register, /auth/pending, /auth/rejected, /dashboard
- Style partage dans src/styles.css avec du CSS par composant

### Lancer en local

1. Installer les dependances : npm install
2. Demarrer le serveur : ng serve

## Backend

- Les endpoints PHP sont dans backend/api
- Le schema de base est dans backend/schema.sql
- Mettez a jour backend/api/config.php avant execution
